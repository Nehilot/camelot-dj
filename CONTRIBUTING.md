# Contributing to Camelot DJ

Thank you for your interest in contributing to Camelot DJ.

## Development Principles

Camelot DJ follows a simple development principle:

> First musical precision, then interface, finally integration.

The musical core must remain independent from the graphical interface and Mixxx integration.

## Before Contributing

Please review the project documentation and understand the current development stage before making changes.

For the initial development phase, priority is given to:

- Musical correctness.
- Clear and maintainable code.
- Automated tests.
- Offline operation.
- Lightweight design.

## Pull Requests

Please keep pull requests focused on a specific change.

When adding or changing core functionality, include or update automated tests when appropriate.

## Reporting Issues

When reporting an issue, provide enough information to reproduce the problem, including the affected functionality and relevant input or output.
